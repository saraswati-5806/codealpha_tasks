# 🛡️ PhishGuard-Lite – Interactive Phishing Awareness Training Platform

> **Think Before You Click. Stay One Step Ahead of Cyber Threats.**

PhishGuard-Lite is an interactive cybersecurity awareness platform developed as part of the **CodeAlpha Cyber Security Internship – Task 2**. Instead of a traditional presentation, this project delivers an engaging online learning experience that teaches users how to recognize and avoid phishing attacks through lessons, simulators, quizzes, and real-world examples.

## ✨ Key Features

### 📘 Interactive Learning

* 🐟 What is Phishing?
* 📧 Email Red Flags
* 🌐 Fake Website Detection
* 🕵️ Social Engineering Awareness
* ✅ Cybersecurity Best Practices
* 🌍 Real-World Phishing Case Studies

### 🧪 Interactive Practice

* 📩 Fake Email Inspector
* 🌐 Fake Website Detector
* 🧠 Smart Quiz Engine
