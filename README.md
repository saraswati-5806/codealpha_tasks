# CodeAlpha Cyber Security Internship Projects

This repository contains all tasks completed during my Cyber Security Internship at CodeAlpha.

## Repository Structure

### Task 1 – NetSniff-Lite

A Python-based Network Packet Sniffer with a modern React dashboard.

**Features**

* Live Packet Capture
* Source/Destination IP Monitoring
* Protocol Analysis
* Payload Inspection
* CSV Logging
* Threat Detection Rules
* Security Report Generation
* Interactive Analytics Dashboard

**Tech Stack**

* Python
* Scapy
* Socket
* Flask
* Flask-CORS
* React.js
* Tailwind CSS v4
* Chart.js
* Lucide React

---

### Task 2 – Phishing Awareness Training

Educational cybersecurity awareness module designed to teach users how to identify phishing attacks and social engineering attempts.

---

### Task 3 – Secure Code Review

Security assessment of application source code with vulnerability identification and remediation recommendations.

## Internship Objectives

* Understand Network Protocols
* Learn Packet Analysis
* Improve Secure Coding Knowledge
* Gain Practical Cybersecurity Experience
* Build Real-World Security Tools
